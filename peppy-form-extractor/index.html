Outstanding Thai Language OCR

The Two-Stage Pipeline powered by PaddleOCR, EasyOCR, Typhoon OCR, and DeepseekOCR delivers exceptional accuracy on Thai-language documents — our strongest capability. Whether you are processing Thai invoices, government forms, receipts, or ID cards, Peppy Form Extractor handles complex Thai script with confidence scores and per-word bounding box precision.

  • Accurate recognition of Thai script, mixed Thai–English documents, and numeric content
  • Per-word bounding boxes with visual confidence colour-coding (green / yellow / red)
  • Drag OCR words directly onto form fields for quick manual correction
  • Works with invoices, tax documents (ใบกำกับภาษี), receipts (ใบเสร็จ), ID cards and contracts
  • PaddleOCR and EasyOCR — battle-tested open-source engines with strong Thai recognition
  • Typhoon OCR and DeepseekOCR — next-generation models, both proven leaders for Thai text recognition

Use Any AI Model You Want — BYOM

The Bring Your Own Model (BYOM) pipeline lets you connect Peppy Form Extractor to any OpenAI-compatible AI provider. Run a private local LLM with Ollama for maximum privacy, or connect to powerful cloud models via OpenAI, Anthropic, or Google. You are never locked in — switch providers at any time with no data loss.

  • Single-shot vision pipeline: image + schema → extracted fields in one API call
  • No Peppy Server required — works entirely from your browser or desktop
  • Configure base URL, API key, model name, temperature and token limits

How It Works

Two Extraction Pipelines

Choose between the high-accuracy two-stage server pipeline or the flexible single-shot BYOM pipeline — configurable per document.

Recommended for Thai Peppy Server PaddleOCR • EasyOCR • Typhoon OCR • DeepseekOCR

Two-Stage Pipeline

Dedicated OCR engine + LLM extraction. Best accuracy, per-word bounding boxes, and ideal for Thai-language documents.

1
OCR Image → text with per-word bounding boxes and confidence scores
2
Classify (optional) Auto-detect document type when set to Auto-detect
3
Extract LLM fills schema fields from OCR text using your custom schema
4
Validate Schema validation rules applied; errors highlighted in the review form
BYOM Any AI Provider

Single-Shot Pipeline ⚡

Vision LLM receives the image and schema in one call — OCR and extraction happen simultaneously, no dedicated server needed.

1
Configure Select document type and set up your AI provider (OpenAI, Ollama, etc.)
2
Single API Call Image + schema sent to your chosen vision LLM — no Peppy Server needed
3
Results Fields populated instantly; optional OCR transcript returned for review
4
Review & Export Edit any field, approve the document, export to Excel / CSV / JSON

Features

Everything You Need for Document Extraction

A complete end-to-end workflow from raw scanned images to structured, validated, exported data.

Batch Processing

Open a folder of scanned images, configure all files at once using the bulk change area, then run OCR and extraction on the entire batch with a single click.

Configurable Schemas

Define custom document schemas (YAML) with typed fields, validation rules, and LLM hints. Supports invoices, receipts, tax forms, ID cards, contracts — any document format you can describe.

Human-in-the-Loop Review

Every extracted document opens in a review form. Edit any field, see validation errors highlighted in red, drag OCR words onto fields, and approve when satisfied.

Private by Design

All results stored in a session.pfe/ folder next to your images. API keys kept in the system keyring, never in plain text. No cloud storage, no third-party data sharing.

Visual BBox Canvas

When using the Two-Stage Pipeline, OCR words are displayed on a canvas overlay with confidence colour-coding. Focus a field to highlight its corresponding words in blue.

Flexible Export

Export results as JSON, CSV (by document type), or Excel (by document type). Each Excel export flattens line-item tables into rows with scalar fields duplicated across them.

Live SSE Streaming

Real-time job status via Server-Sent Events. Status badges animate as each file moves through OCR, classification, extraction, and validation — no page refresh needed.

Schema Configuration

Create your own document schemas using the built-in Schema Configuration panel — no YAML editing required. Define field names, types, validation rules, and LLM hints. Schemas update all Document Type dropdowns instantly.

Peppy Server API

Integrate document extraction into your own applications via the Peppy Server REST API. Submit jobs programmatically, stream results over SSE, and retrieve structured JSON — ideal for automated pipelines and back-office workflows.

Keyboard Navigation

Press T to toggle between Preview and OCR tabs. Use ← / → to navigate between documents without touching the mouse.
